# logisticsV2

Streamlit-приложение для маршрутизации Gloria Jeans Logistics (VRPTW).

## Локальный запуск

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Деплой в Streamlit Community Cloud

- Repository: `Fayvz501/logisticsV2`
- Branch: `main`
- Main file path: `app.py`

После подключения GitHub приложение будет доступно как веб-приложение и автоматически обновляться после новых коммитов.
